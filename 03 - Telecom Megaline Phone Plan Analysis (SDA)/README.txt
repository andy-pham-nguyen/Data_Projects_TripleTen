# 📱 Telecom Megaline Phone Plan Analysis (SDA)

## 📌 Overview
This project analyzes customer behavior for the Megaline telecom company to determine which phone plan—Surf or Ultimate—is more profitable. Using statistical analysis, the project evaluates call patterns, message usage, internet consumption, and monthly revenue to guide business decision-making.

## ✨ Features
- Full data cleaning and preprocessing  
- Statistical comparison between Surf vs. Ultimate plans  
- Hypothesis testing on user behavior and revenue  
- Analysis of call duration, messages, and data usage  
- Visualizations for plan comparisons and customer trends  

## 🛠 Tech Stack
- Python 3.10+  
- Pandas, NumPy, SciPy  
- Matplotlib, Seaborn  
- Jupyter Notebook  

## 📊 Key Insights (Summary)
- Ultimate users generally spend more on average due to higher plan fees  
- Surf users tend to exceed included minutesdata more frequently  
- Internet usage shows strong growth across both plans  
- Hypothesis tests help validate whether user behavior differs significantly between plans
