# 🧠 Automated Age Verification System (Computer Vision)

## 📌 Overview
This project builds a computer vision system to estimate a person’s age from facial images using deep learning. The goal is to help retail stores automate age verification for alcohol sales and reduce human error in compliance checks.

A convolutional neural network (CNN) was trained on a large facial image dataset to predict customer age and evaluate whether automated verification could be feasible in a real-world retail environment.

---

## ✨ Features
- Image preprocessing and normalization  
- Exploratory data analysis (EDA) on age distribution  
- Convolutional neural network (CNN) model training  
- Model evaluation using Mean Absolute Error (MAE)  
- Visualization of predictions vs. actual ages  
- Business feasibility assessment for retail deployment  

---

## 🛠 Tech Stack
- Python 3.10+
- Pandas, NumPy
- TensorFlow / Keras
- OpenCV
- Matplotlib, Seaborn
- Jupyter Notebook

---

## 📊 Key Results
- Trained a CNN to predict customer age from facial images  
- Achieved a reasonable MAE indicating viable age estimation performance  
- Model performance suggests automated age verification could assist retail staff but should not fully replace manual ID checks  
- Identified challenges such as dataset bias and facial feature variability
